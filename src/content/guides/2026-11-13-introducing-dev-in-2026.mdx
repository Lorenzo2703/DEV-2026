Dev in 2026 is a handbook for developers who need more than a list of tools. Each guide aims to
show how a technology fits into a working system, what to verify, and which trade-offs matter.

## Start with the implementation

The handbook pairs concise explanations with examples that can be checked in the repository. Tool
guides record when their current details were verified, and runnable samples are exercised as part
of the project checks.

## Choose deliberately

The technology radar records where this handbook adopts, trials, assesses, or holds an approach.
Blueprints and cross-cutting guides connect those decisions to practical system boundaries, rather
than treating a stack as a collection of unrelated product choices.

## Keep it current

Software changes quickly, so this is an ongoing reference rather than a claim that one stack suits
every project. Check the verification date and linked sources before applying time-sensitive advice,
and use the examples as a starting point for your own requirements and constraints.
