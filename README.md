# Dev in 2026

A practical handbook for building, shipping, and operating software.

## Requirements

- Bun 1.3.10
- Node.js 22.23.4 or newer

Use `mise` to install the pinned runtimes, then run `bun install`.
Search uses the Pagefind index generated by `bun run build`; preview the built site to test search.
The pinned pnpm and Yarn development dependencies are used only to execute the package-manager command examples; Bun remains the project's package manager.
Set `SITE_URL` to the final HTTPS origin (without a path) when building for publication. Canonical URLs, RSS feeds, and the sitemap are omitted with a warning until it is set. Configure the `SITE_URL` variable in the GitHub `production` environment before deploying.

For local deployment, put the production origin, Cloudflare account ID, and a scoped Cloudflare API token in the ignored `.env` file. Bun loads it for the build and Wrangler loads it for deployment; it contains plaintext, so do not commit or share it. The `.env.example` file contains placeholders only. GitHub Actions does not read your local file: configure `CLOUDFLARE_ACCOUNT_ID` and `CLOUDFLARE_API_TOKEN` as `production` environment secrets in GitHub.

Analytics is disabled by default. To enable the self-hosted Umami integration in [ADR-0001](docs/adr/ADR-0001-analytics.md), place a verified tracker script under `public/` and set `UMAMI_SCRIPT_PATH` to its root-relative URL, `UMAMI_HOST_URL` to the HTTPS collector origin, and `UMAMI_WEBSITE_ID` to the site's UUID. Set all three as build environment variables (or production environment variables in GitHub); these values are public, not secrets. The build rejects incomplete configuration or a missing tracker. Configure retention, security, and privacy notices for the deployment before enabling collection.

Enable Renovate and protect the main branch with the CI verification job as a required check. Patch updates can then automerge only after checks pass; minor updates remain reviewable. The release-age cooldown depends on timestamps provided by each package source.

## Commands

| Command                  | Purpose                                                                                      |
| ------------------------ | -------------------------------------------------------------------------------------------- |
| `bun run dev`            | Start the Astro development server                                                           |
| `bun run build`          | Build the static site and Pagefind index                                                     |
| `bun run check`          | Run Astro, TypeScript, and Biome checks                                                      |
| `bun run test`           | Run unit tests                                                                               |
| `bun run test:e2e`       | Run Playwright end-to-end tests                                                              |
| `bun run snippets`       | Type-check and run snippet packages                                                          |
| `bun run verify:content` | Validate frontmatter, required headings, snippet references, and report staleness            |
| `bun run stale-report`   | Report stale or explicitly unverified tools (`--check-versions` also checks release sources) |
| `bun run links`          | Check links with lychee after building the site                                              |

See `CLAUDE.md` for content requirements and project decisions.
