# Tool Registry

This registry contains the ten flagship tools explicitly suggested in `CLAUDE.md`, plus the requested M3 backlog. Existing flagship entries retain their evidence-backed seeds. For each new entry, verify official documentation, changelog, latest stable version, license, pricing, maturity, and radar position before authoring a page; add implementation and failure-mode notes from those sources. The research focus is an editorial prompt, not a claim that has already been verified.

## Scoped technology paths

These are starting-point recommendations, not required bundles or verified compatibility claims. Choose only the companions that fit the application; `or` means choose one. When authoring the pages, use these paths to select relevant `related` links and explain when each companion is unnecessary.

| Starting point / scope | Suggested companions | Scope guidance |
| ---------------------- | -------------------- | --------------- |
| Python API or service | Python + uv; Ruff; FastAPI + Pydantic; pytest; PostgreSQL + SQLAlchemy when relational persistence is needed | Use uv for project environments and locked dependencies; add FastAPI for an HTTP API, Pydantic for runtime boundaries, and a database only when the service needs persistence. |
