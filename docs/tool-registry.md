# Tool Registry

This registry contains the ten flagship tools explicitly suggested in `CLAUDE.md`, plus the requested M3 backlog. Existing flagship entries retain their evidence-backed seeds. For each new entry, verify official documentation, changelog, latest stable version, license, pricing, maturity, and radar position before authoring a page; add implementation and failure-mode notes from those sources. The research focus is an editorial prompt, not a claim that has already been verified.
